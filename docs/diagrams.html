                     |                    |
   side channels:    |                    |
   every node ---->  | cost_ledger[]      |  (CostEntry per call)
                     | errors[]           |  (NodeError per failure)
                     +--------------------+

   Contract rule:  nodes only WRITE their own slot;
                   downstream nodes READ upstream slots.
                   No node mutates a slot it didn't own.

6. My Role vs AI's Role

SKILL.md two-column close
Pattern from skills/my-working-style/SKILL.md Phase 10

Sri's decisions

  • Picked option 3 (reel generator) over the simpler options
  • Decided to deploy live (studio.sshub.dev) instead of demoing locally
  • Chose LangGraph over the JD-suggested n8n; wrote ADR-001 to defend it
  • Designed the 4-node decomposition (Extract / Plan / Execute / Stitch)
  • Made the human-approval gate mandatory, not optional
  • Set the daily cost cap as a hard wall before paid calls
  • Wrote the 10-probe fail-fast matrix as a phase gate
  • Picked Hetzner + nginx + basic auth + Let's Encrypt for the deploy
  • Branded the product as Sri Studio with the matching subdomain
  • Decided plan.json is the single auditable artifact pre-spend
  • Picked Flux Schnell, ElevenLabs voice clone, captions-via-alignment
  • Chose 5s default with 90s on tape for the walkthrough

Claude Code's implementation

  • Wrote the FastAPI routes, SSE plumbing, and run registry
  • Wrote the LangGraph state machine wiring and node functions
  • Wrote the Pydantic models for ReelState / ScriptPlan / Scene
  • Wrote the ffmpeg filtergraphs (Ken Burns, caption burn-in, mix)
  • Wrote the Replicate Flux client incl. NSFW retry
  • Wrote the ElevenLabs TTS client + char-to-word grouping
  • Wrote the cost-cap helper and pre/post pricing print pattern
  • Wrote every probe script under my direction
  • Wrote the Next.js components: PromptForm, PlanReviewPanel, ReelPlayer, CostLedger
  • Wrote the nginx config and the deploy script
  • Wrote the docker-compose stack and Dockerfiles
  • Wrote and validated the Langfuse v4 decorator pattern
The Pattern

I identify problems, design solutions, choose technologies, craft prompts, and direct architecture. Claude Code turns those decisions into working code, fast and reliably. The skill is knowing what to build and when to intervene.
